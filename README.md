# AF-PINN

Code for **"Adaptive-Frequency Physics-Informed Neural Networks for Multi-Scale Charged-Particle Dynamics in Tokamak Fields"**.

## Requirements

```
pip install -r requirements.txt
```

## Structure

```
├── src/pinn_main.py              # Core library (physics, models, training)
├── weights/                       # Pre-trained weights for States A-D
├── experiments/
│   ├── forward/
│   │   ├── 2500.py               # Forward problem (multi-seed training)
│   │   └── draw.py               # Post-hoc plotting
│   └── ablation/
│       ├── config_ablation.py    # Ablation: FF, E, Pφ
│       ├── w_ablation.py         # Ablation: frequency input modes
│       ├── method_comparison.py  # AF-PINN vs baselines
│       └── plot_scripts/         # Post-hoc plotting
└── .gitignore
```

## Usage

```bash
# Forward problem
cd experiments/forward && python 2500.py

# Ablation study
cd experiments/ablation && python config_ablation.py

# Method comparison
cd experiments/ablation && python method_comparison.py

# Frequency input ablation
cd experiments/ablation && python w_ablation.py
```

Plotting scripts in `plot_scripts/` and `forward/draw.py` require `.pkl` data generated by the training scripts above.

The pre-trained weights under `weights/` correspond to 2500-step forward training on States A-D and can be used directly for validation without re-running training.

## Notes

- Hyperparameters (learning rate, epochs, network width, etc.) are in `src/pinn_main.py` at the top of the file and in the `train_pinn()` function.
- To change the number of time-steps from 2500 to another value like 500, modify `n_steps` at line 36 of `src/pinn_main.py`. The time interval and `t_max` will adjust accordingly.
